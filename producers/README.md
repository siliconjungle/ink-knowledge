
`action_values.py` emits three general carrier entries alongside a complete
source image. Values use flat postorder nodes with balanced transport, binary
exact-integer magnitudes and full nominal/type correspondence. It needs no
aggregate certificate. Its independent `encode` function agrees with Ink's
bounded codec on supported action values. Admission checks exact definitions and
source data; these entries do not certify an interpreter or a replacement.
See ink-lang `docs/action-values.md` for the format and replay commands.

`representations.py --cache-query NAME --preserve-cache` proposes source-bound
cache retention after aborted changes/host failure and unrelated committed
writes. `cache_maintenance.py` generates universal branch equations using the
existing equality rules. Dependency analysis is an untrusted authoring heuristic;
only checking the exact source-bound equations grants selection authority.
See `research/cache-maintenance` for frozen requests and replay instructions.

`representations.py --compact-queries` avoids carrying a second copy of table
roots through query execution. Cached query replies reconstruct their next tuple
directly; ordinary queries carry only the cached value where needed. Every
observation/preservation equation is still checked. See `research/compact-queries`
for frozen requests, migration, comparable cost observations and executor limits.

Engine40 target-work diagnostics are optional external acquisition tools:
`target_work40_js.mjs` and `target_work40_c.py` instrument literal emitted sites;
`target_work40_prepare_js.py` binds the frozen suite and replays its exact captured
JavaScript boundary untimed. Missing C/Rust/Wasm/GPU boundary work is not supplied
from JavaScript. `web_cost40.py` freezes separately fitted target/host/boundary/
emitter prices and predictions before heldout evaluation. It uses only explicitly
supplied training labels and leaves defaults unchanged.

`import_target_work40.py` prepares canonical diagnostic definitions, price
JSON and measured observations without publishing. Namespaces
`ink-target-work-measurement-v1` and `ink-target-work-prices-v1` carry no theorem
or application authority. Exact fractional samples and model JSON remain bound;
the observation index retains its existing rounded integer timing format and
unknown peak memory. The publisher must retain ordinary snapshot-bound candidate
checking. Full contract and offline acquisition exclusions are documented in
`planner/docs-physical-features.md` in the distribution checkout.

Physical import optionally accepts `--context CONTEXT.json`. The general bound
publication context is embedded, with its exact content hash, in every measurement
and price entry and recorded as a diagnostic dependency. This carries acquisition
limitations, poor heldout outcomes and environmental contention alongside prices;
it cannot supply a theorem or application condition. Context source mutation is
rejected. Frozen model JSON, predictions and evaluation remain unchanged.

`indexed_aggregate.py` authors ordered range-indexed sequence trees with cached
filtered u64 sum/count, checked rotations and full-action representation proofs.
`--publish-root` requires an exact source replay before catalog publication and
retains a compact immutable view pin. `state_laws.py` publishes parametric field
frame/dependency laws and grouped edits preserving intermediate and final rows.
`representation_bridge.py --via-logical` uses each target relation's checked
initialisation theorem, supporting multi-relation decode/encode migrations.

`reactive_dependencies.py` proposes dependency-factorisation, equal-value downstream
reuse and branch-sensitive dependency laws. Concrete instances must discharge
factorisation assumptions, exact dependency equality and selector equality. Read
traces and profiles cannot discharge them. `--publish` stages mathematical
admission before adding the immutable entries and retains the old snapshot.
The distribution's `docs/signals-state-performance.md` records scope and replay.

`word_laws.py` proposes stored first-order U32/U64/Bool equalities only at
matching source sites. Its compressed certificates in `data/source-word-laws.json.gz`
are untrusted: `laws::Proof::Word` reconstructs finite-word circuits and replays
RUP in the compiler. Matching and candidate labels grant neither equality nor
profitability. The initial laws cover ASCII case ranges, modular cancellation,
a conditional increment comparison and Boolean choice. They need the new word
proof checker; older compilers reject this proof variant. Unsigned shifts and
rotations, signed arithmetic and whole scanner replacement are not admitted by
these laws. Conditional laws still require checked premises at each application.

V8-inspired fixed-width and branch proposals live in `v8_word_laws.py`.
`author_word_identities --family v8 --library` authors them offline with the
ordinary hinted-RUP checker. `frozen_laws.py` maintains an atomic pattern index
and separate content-addressed proof files; discovery opens matched proofs only.
The index is an untrusted discovery aid. Conditions, source binding and every
proof still require independent checking; no V8 feedback grants authority.

`frozen_specialization.py` materializes frozen F32 coefficients as exact finite
literals or exceptional-value bitcasts, including nested records and lists.
Value classification is separate from equality folding: floating comparisons
remain source operations, while `point_delta.normal` preserves non-integer
operators for ordinary kernel conversion. Whole-action proofs must replay under
the checked frozen domain; scores and explicit configuration supply no theorem.
The distribution's frozen numeric example checks retained live data, raw NaN bits,
signed zero, rollback and complete compiled snapshots. This is bounded proposal
tooling, not universal graph unrolling or automatic profitable specialization.

Closed-list `foldl`/`foldr` proposals now bind each accumulator once under fresh
names and preserve iteration/IEEE operation order. Literal operation choices can
disappear while weights remain mutable. The proposer does not calculate floating
arithmetic or invent equality facts; the complete checked action proof decides
admission. Source/continuation/canonical-value bounds still limit larger graphs.
The proposer first transports exact frozen rows through source case forms without
fully expanding live arithmetic. Ordinary checking must accept that compact
proof; otherwise it retries the existing normalization tactic. Both failures
leave a prior selection file untouched. This reduces repeated proof payloads,
not the equality obligations or the frozen-row restore contract.
