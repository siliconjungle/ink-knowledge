a nested weighted zip followed by an original-input gate. Both mapped-value
targets use an existing unary beta application to bind the predicate callback's
result once. The left gate selects that result when it is `< d`, otherwise

retains `x + x*k` with the exact multiplication/addition grouping, choosing it
