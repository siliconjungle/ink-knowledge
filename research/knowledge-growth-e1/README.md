# Frozen execution, reusable data

Six type templates supply two reusable proof schemes: absorbing Boolean left folds
(two endpoints and two support lemmas) and controlled map/filter consumption
(two endpoints in one family). They extend existing early-exit and fusion ideas;
types, lemmas, adapters and endpoints are not separate algorithm families.

`checked-view.json` contains 36 independently checked representative instances
and their complete dependency closures. Templates are untrusted authoring data;
every new carrier and exact source application still needs ordinary kernel
admission. The ordinary `controlled-folds.ink` library uses typed records for
callback state and marked-row intermediate data, without new host capabilities.

The distribution report `reports/knowledge-growth-2026-10-13/README.md` retains the
frozen machine/package revisions, source/input corpus, forced and default lanes,
regressions, timing uncertainty, memory observations and all candidate replay.
The default planner retained the baseline in all 30 ordinary builds. Forced-port
improvements do not establish independently chosen whole-software acceleration.
