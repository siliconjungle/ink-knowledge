# membership-cache

The gzip file is a canonical, sorted compact JSON representation request, with
its authenticated mathematical dependency closure. It contains no native code
or performance authority. `source.ink` pins the complete source module.

Reproduce with the distribution's `tools/reproduce_scalable_knowledge.py`, or
project this source using `ink emit-action-model`, then run:

```sh
python3 producers/representations.py model.json --cache-query intersection \
  --preserve-cache --compact-queries --membership-query -o proposal.json
```

The second request is the maintained candidate; check it with
`ink check-representation source.ink request.json` before emission. The root
`representation_parity` suite exercises it through compiled C, Rust, JavaScript
and both Wasm lanes. Re-signed false laws are separately rejected.
